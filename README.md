# 🚀 AI-Powered Datasheet Manager & Catalog Assistant

**Datasheet AI Manager** is a comprehensive desktop application designed to solve the chaos of unformatted, scattered hardware and engineering datasheets. 

🤖 **Zero-Code / Prompt Engineering Project:** 
This entire application was developed **without any prior software development or coding background**. The complete architecture, backend, frontend, and AI integrations were built entirely by writing precise prompts and managing AI tools (Prompt Engineering). It serves as a proof of concept for how AI can be leveraged to build full-scale, production-ready software solutions.

## ✨ Key Features

* 🔍 **Smart Searchbox:** Instantly find any datasheet in your local directory with a single click.
* 🔄 **AI-Driven Standardization (Gemini API):** The app scans decades of datasheets created in completely different formats and uses AI to convert them into a single, uniform layout.
* ✏️ **Easy Editing & PDF Export:** Found an error in a legacy datasheet? Easily edit the data within the app and export the corrected version as a clean PDF in seconds.
* 📝 **Manual Management & Notes:** Take specific notes on products, manually create new datasheets, or organize missing files into folders.
* 🧠 **AI Catalog Assistant:** An integrated chatbot that analyzes both your locally loaded datasheets and web data to answer any technical questions you have about the products.
* 🌗 **Modern UI:** User-friendly interface with both Dark and Light mode support.

## 🛠️ Tech Stack (Generated by AI)
* **Backend:** Java (Maven, JavaFX)
* **Frontend:** HTML, Vanilla JavaScript, CSS
* **AI Integration:** Google Gemini API

## 🚀 How to Run

1. Clone this repository to your local machine.
2. Navigate to `src/main/java/com/pilsan/datasheet/AppSecrets.java` and enter your own Gemini API Key.
3. Run the application using the provided scripts:
   * **Mac/Linux:** Open terminal in the project directory and run `sh start.sh` or `mvn clean javafx:run`
   * **Windows:** Double-click the `start.bat` file.
